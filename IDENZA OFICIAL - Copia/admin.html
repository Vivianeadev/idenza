Manual do Painel de Controle IDEnza

1. Visão Geral

O Painel de Controle é a interface administrativa da plataforma IDEnza. Aqui você gerencia assinantes (empresas clientes), monitora licenças, acompanha o fluxo de caixa e toma decisões operacionais. Todas as ações são refletidas em tempo real no banco de dados da plataforma.

2. Navegação

  • Sidebar: à esquerda, contém links para as seções principais (Assinantes, Fluxo de Caixa) e acesso rápido à página pública.
  • Abas superiores: alternam entre a lista de assinantes e a visualização financeira.

3. Gerenciamento de Assinantes

A aba "Assinantes" exibe todas as empresas cadastradas na IDEnza. Para cada assinante, você visualiza:

  • Nome da empresa, plano contratado, status (ativo/inativo), chave API, créditos disponíveis e data de cadastro.
  • Ações rápidas: botões para Ativar/Desativar licença e Excluir empresa.

Ativar/Desativar: uma licença inativa impede o uso da API (a chave fica bloqueada), mas os dados permanecem. Útil para suspender temporariamente um cliente inadimplente.

Excluir: remove permanentemente a empresa e todos os dados associados (usuários, carteira, logs). Esta ação não pode ser desfeita — use com cautela.

Os cards no topo mostram o total de assinantes, quantos estão ativos, inativos e a receita mensal recorrente (soma dos planos ativos).

4. Fluxo de Caixa

A aba "Fluxo de Caixa" fornece uma visão financeira consolidada:

  • Saldo em Caixa: dinheiro disponível na conta da IDEnza (valores líquidos recebidos).
  • Receita/Despesas do mês: entradas (assinaturas, pagamentos avulsos) e saídas (custos de infraestrutura, provedores de IA).
  • Lucro Líquido: receita menos despesas.
  • Tabela de transações: lista as movimentações recentes, com data, descrição, valor e tipo (entrada/saída).

Esses dados são atualizados automaticamente conforme eventos na plataforma (novas assinaturas, débitos de créditos, etc.).

5. Funcionalidades Administrativas

Além da gestão de assinantes, o painel permite:

  • Criar novo assinante manualmente: (em breve) botão para cadastrar empresas diretamente pelo admin.
  • Alterar plano e limites: (em breve) editar detalhes da licença, como mudar de Starter para Professional, ajustar créditos.
  • Exportar dados: (planejado) exportar lista de assinantes e transações para CSV.

6. Segurança e Responsabilidades

Este painel é restrito a administradores autorizados. Mantenha suas credenciais em sigilo. Todas as ações realizadas são registradas em logs de auditoria (visíveis apenas para super administradores). Recomendamos revisar periodicamente os assinantes e o fluxo de caixa para garantir a saúde do negócio.

Para suporte, contate admin@idenza.com.
