# Idenza Robotics Academy v6.0.0

> **Academy & Diagnostic Engine** — Ecossistema completo de aprendizado, diagnóstico e criação em robótica, IoT e inteligência artificial.

---

## 🚀 Sobre o Projeto

A **Idenza Robotics Academy** é uma plataforma web modular para:

- 📊 **Diagnóstico** de sistemas robóticos em tempo real
- 🎓 **Ensino** de robótica, IoT e IA com trilhas completas
- 📁 **Portfólio** de projetos com BOM e passo a passo
- 📦 **Catálogo** de hardware e kits curados
- 🧪 **Simulador** de falhas para treinamento
- 🛒 **Loja** de kits educacionais
